# Личная устойчивость

Программа Андрея Шумеляка.

Сайт: https://shumelyakam.github.io/lichnaya-ustoychivost/

На странице работает форма: фамилия, имя, почта и телефон. Заявки сохраняет сервер Sites в закрытую Cloudflare D1. Доступа к чтению контактов через публичный сайт нет.

GitHub Pages хранит только HTML. Базы данных, персональных данных и секретов в этом публичном репозитории нет. Локальная SQLite и интернет-база не синхронизируются автоматически.
