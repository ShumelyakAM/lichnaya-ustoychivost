# Содержание сайта

`articles.json` содержит название, описание, дату и категорию каждой статьи. Текст статьи хранится отдельно в `articles/<slug>.html`. После изменения или добавления статьи запустите `tools/build_site.py`: страница, карточки блога, ссылки на главной и карта сайта обновятся вместе.

`products.json` содержит карточки каталога. Для нового продукта добавьте объект с уникальным `slug`, полями `title`, `category`, `format`, `status`, `description`, `audience`, `includes` и `visible: true`. Если у продукта уже есть отдельная страница, укажите `landing` с адресом внутри сайта. Иначе сборщик создаст страницу по общему шаблону. Не добавляйте цену, дату старта или обещания результата без утверждённого решения.

`program.json` содержит пять модулей текущей программы. Остальной текст её подробной страницы редактируется в `public-site/index.html` рабочего проекта или в `index.html` опубликованного репозитория; сборщик сохраняет его и обновляет только блок модулей, навигацию и метаданные.

Команда сборки из корня проекта:

```text
python tools/build_site.py
python tools/check_site.py
```

Для сборки нужен Python с библиотекой `lxml`. В рабочем проекте сгенерированные страницы находятся в `public-site/`. В репозитории GitHub Pages они лежат в корне; сборщик поддерживает обе структуры.
